# बायीसी सांख्यिकी की कक्षा
कक्षा से पहले सारे आवश्यक प्रोग्राम और संचिका तैयार रखने के लिये निम्नलिखित निर्दशों को पालना।

## १. PyCharm या VSCodium स्थापित करना
पैथान एक संगणक की भाषा है जिस का प्रयोग इस कक्षा में किया जाएगा। पैथान लिखने के लिये अलग-अलग साफ्तवेर हैं, जिनमें से पैचार्म और वीयेसकोडियम अच्छे विकल्प हैं।
पहले से ही इनमें से एक साफ्तवेर स्थापित कर लेना (आपकी मर्ज़ी के अनुसार)।

* पैचार्म के लिये - https://www.jetbrains.com/pycharm/download
* वीयेस्कोडियम के लिये - https://vscodium.com/

## २. Python स्थापित करना
`python` को स्थापित करने का दो विकल्प हैं, `python.org` से सीधे लेना या फिर `pyenv` से पाना।
**Anaconda का पैथान का प्रयोग नहीं करना।** अगर मेरी इस बात नहीं मानते हैं मैं तो ज़िम्मेदारी नहीं हूँ।

### Python.org से
https://www.python.org/ के "Downloads" पर क्लिक करके और पैथान का अधोभारण करके उसको स्थापित कर लेना।

### या तो pyenv से
निर्देशों के लिये निम्नलिखित संपर्क को खुल लेना।
* https://github.com/pyenv/pyenv#installation

फिर इस टर्मिनल में इस आज्ञा देना।
> pyenv install 3.12

## ३. git स्थापित करना

https://git-scm.com/install/

> git clone https://github.com/julienmalard/bayes-kaksha.git

## ४. pdm स्थापित करना
पैथान में हम अलग-अलह पैकेज के प्रयोग करेंगे जिस से बायीसी सांख्यिकी असान से की जाएगी।
पैथान में इन पैकेज का नियंत्रण करने के लिये हम `pdm` का प्रयोग करेंगे। 
`pdm` को निम्नलिखित संपर्क से स्थापित कीजिये।

* https://pdm-project.org/en/latest/#recommended-installation-method

## ५. कक्षा का उदाहरण संकेत को पाना  
PyCharm या VSCodium खोलके, `git project` में https://github.com/julienmalard/bayes-kaksha
को खोल लेना।

न तो सीधे इस आज्ञा से क्लोन कर देना।
> git clone https://github.com/julienmalard/bayes-kaksha

उसके बाद पैचार्म या वीयेस्कोडियम का टेर्मिनल खोलके, निम्नलिखित आज्ञा भेज देना। 
> pdm install

## ६. देख लें कि क्या सब सफल से कर लिये है 
`स्थापन जाँच.py` नाम की संचिका पर क्लिक करके उसको चलाना। अगर अंत में "सब ठीक ठाक है" का संदेश आता है तो सब ठीक ठाक है। 
अगर नहीं आता तो सब ठीक नहीं है और मुझसे संपर्क कर लेना।
